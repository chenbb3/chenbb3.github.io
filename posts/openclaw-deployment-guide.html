OpenClaw 部署与配置完全指南 ​

OpenClaw 是一个强大的 AI 助手框架，支持多平台部署。本文详细介绍如何在 Windows 上部署 OpenClaw、卸载重装、配置 Discord 频道以及配置模型。

系统要求 ​

  • Node.js 22+
  • macOS、Linux 或 Windows
  • 推荐使用 WSL2（在 Windows 上）

一、安装 OpenClaw ​

方式一：安装脚本（推荐） ​

方式二：npm / pnpm ​

bash
npm install -g openclaw@latest
openclaw onboard --install-daemon

验证安装 ​

bash
openclaw status

二、卸载 OpenClaw ​

方式一：使用卸载命令（推荐） ​

如果 CLI 仍然安装：

bash
openclaw uninstall --all --yes --non-interactive

或者分步执行：

bash
# 1. 停止网关服务
openclaw gateway stop

# 2. 卸载网关服务
openclaw gateway uninstall

# 3. 删除状态和配置
rm -rf "${OPENCLAW_STATE_DIR:-$HOME/.openclaw}"

# 4. 删除 CLI
npm rm -g openclaw

方式二：手动卸载（CLI 已删除） ​

Windows ​

powershell
schtasks /Delete /F /TN "OpenClaw Gateway"
Remove-Item -Force "$env:USERPROFILE\.openclaw\gateway.cmd"

三、配置 Discord 频道 ​

步骤 1：创建 Discord Bot ​

  1. 访问 Discord Developer Portal
  2. 创建一个新应用
  3. 添加 Bot 用户
  4. 启用以下 intents：
    • Message Content Intent（必需）
    • Server Members Intent（推荐）

步骤 2：配置 Token ​

编辑配置文件 ~/.openclaw/openclaw.json：

json5
{
  channels: {
    discord: {
      enabled: true,
      token: "YOUR_BOT_TOKEN",
    },
  },
}

或者使用环境变量：

bash
DISCORD_BOT_TOKEN=your_token_here

步骤 3：邀请 Bot 并启动网关 ​

  1. 使用管理员权限生成邀请链接
  2. 启动网关：
bash
openclaw gateway

步骤 4：配对第一个 DM ​

bash
openclaw pairing list discord
openclaw pairing approve discord <CODE>

配对码有效期为 1 小时。

四、配置模型 ​

OpenClaw 支持多种模型提供商，以下是配置示例：

MiniMax（默认） ​

首次运行时会自动引导配置。

Ollama（本地模型） ​

  1. 确保 Ollama 已安装并运行
bash
ollama serve
  1. 查看可用模型：
bash
curl -s http://localhost:11434/api/tags
  1. 在配置文件中添加：
json5
{
  models: {
    providers: {
      ollama: {
        baseUrl: "http://localhost:11434",
        api: "ollama",
        models: [
          {
            id: "qwen3:8b",
            name: "Qwen3 8B",
            reasoning: false,
            contextWindow: 32768,
            maxTokens: 4096,
          },
        ],
      },
    },
  },
  agents: {
    defaults: {
      models: {
        "ollama/qwen3:8b": {
          alias: "qwen3",
        },
      },
    },
  },
}

配置默认模型 ​

json5
{
  agents: {
    defaults: {
      model: {
        primary: "minimax-portal/MiniMax-M2.5",
      },
    },
  },
}

使用别名切换模型 ​

在对话中可以直接使用别名切换模型：

  • /model qwen3 - 切换到本地 qwen3
  • /model minimax-m2.5 - 切换到 MiniMax M2.5

常用命令 ​

命令说明
openclaw gateway start启动网关
openclaw gateway stop停止网关
openclaw gateway status查看网关状态
openclaw config get查看当前配置
openclaw config patch修改配置
openclaw pairing list查看配对列表
openclaw pairing approve批准配对

总结 ​

本文介绍了 OpenClaw 的完整部署流程，包括：

  1. ✅ 安装 OpenClaw（多种方式）
  2. ✅ 卸载 OpenClaw（CLI 和手动）
  3. ✅ 配置 Discord 频道
  4. ✅ 配置模型（MiniMax、Ollama）
