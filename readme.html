老陈的知识库 ​

个人技术博客，记录学习，记录生活。

项目说明 ​

基于 VitePress 构建的静态博客，部署在 GitHub Pages。

项目地址
🌐 线上博客chenbb3.github.io
📦 源码仓库chenbb3/blog-source
🚀 部署仓库chenbb3/chenbb3.github.io

目录结构 ​

├── docs/
│   ├── .vitepress/
│   │   └── config.mts       # VitePress 站点配置
│   ├── public/               # 静态资源
│   ├── index.md              # 首页
│   ├── about.md              # 关于页面
│   ├── readme.md             # 本文件
│   └── posts/                # 博客文章
│       ├── index.md          # 文章列表
│       ├── hello-world.md
│       ├── openclaw-deployment-guide.md
│       └── superpowers-guide.md
├── deploy.sh                 # 一键部署脚本
├── package.json
└── .gitignore

日常维护 ​

本地预览 ​

bash
npm run docs:dev

写新文章 ​

  1. 在 docs/posts/ 下新建 .md 文件
  2. 更新 docs/posts/index.md 添加文章链接
  3. 更新 docs/.vitepress/config.mts 的 sidebar 添加侧边栏入口

提交源码 ​

bash
git add -A
git commit -m "描述更新内容"
git push

部署上线 ​

bash
bash deploy.sh

技术栈 ​

  • 框架: VitePress v1.6.4
  • 部署: GitHub Pages
  • 主题: 默认主题（支持深色模式）
  • 搜索: 本地全文搜索
